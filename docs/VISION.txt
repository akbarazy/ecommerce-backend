# ANALYSIS
## WBS
- product variant
  - membuat entity variant
  - membuat repository variant
  - menyesuaikan repository cart item
  - menyesuaikan entity product, cart item, dan order item
  - membuat request dan response variant
  - menyesuaikan request dan response cart item, response product
  - menyesuaikan service product, cart, dan order 
  - menyesuaikan CreateProductRequest (menghapus field obsolete price, stock, imageUrl atau mendukung initial variants)
  - memperbaiki ProductSpecification untuk filter minPrice dan maxPrice (join ke entity Variant dengan query distinct)
  - membuat VariantService dan VariantServiceImpl
    - implementasi addVariantToProduct (validasi produk exist dan SKU unik)
    - implementasi getVariantById dan getVariantsByProductId
    - implementasi updateVariant (update SKU, atribut warna/ukuran, harga, stok, dan image)
    - implementasi deleteVariant (validasi data keterkaitan order/cart)
  - membuat AdminVariantController untuk manajemen varian
    - endpoint POST /api/admin/products/{productId}/variants
    - endpoint GET /api/admin/products/{productId}/variants
    - endpoint PUT /api/admin/variants/{id}
    - endpoint DELETE /api/admin/variants/{id}
  - mendaftarkan konfigurasi keamanan endpoint variant di SecurityConfig (ROLE_ADMIN)
  - memperbaiki unit test yang rusak akibat pemindahan atribut ke variant
    - ProductServiceImplTest
    - AdminProductControllerTest
    - ProductControllerTest
  - membuat unit test untuk VariantService dan AdminVariantController
  - menguji integrasi alur bisnis (add to cart, validasi stok, checkout, dan pengurangan stok varian)
  - memperbarui dokumentasi DESIGN.md (API Visualization) dan VISION.txt (Fitur Admin)
